## Sprint 5（v1 新编号）: 客户端基础 (2026-09，Week 1-4)

**目标**：Cocos Creator 出登录、大厅、房间三个页面，与战斗服真机打通

| ID | 任务 | 验收标准 |
|---|---|---|
| T-501 | 安装 Cocos Dashboard + Creator 3.8.x，跑通微信小游戏构建 | 模拟器 + 真机预览 OK |
| T-502 | Cocos 工程分层（场景/脚本/资源/网络层） | 单文件不超过 300 行 |
| T-503 | WebSocket 客户端封装（含心跳/重连） | 掉线 30 秒内自动重连（对接现有 `ws://host/ws` 协议） |
| T-504 | 注册个人小游戏账号（避开"棋牌桌游"类目，选个人可选类目） | 拿到 AppID |
| T-505 | 登录页（微信授权静默登录）+ 大厅（建房/加入） | 真机能进房间 |
| T-506 | 房间页：4 座位 + 3 bot 自动开局 | 真人 NORTH 入座即开局（复用 ServerMain 形态） |

**Demo**：一部手机建房，3 个 bot 补位，真人入座自动开局。

**后端配合任务**（非关键路径，穿插做）：
- T-510：WS 鉴权——会话令牌绑定 playerId（体检发现的 🔴 漏洞：目前可冒充任意玩家）
- T-511：RedisStateStore 异步化 + 故障降级内存

## Sprint 6: 牌桌 UI + 实时同步 (2026-10，Week 5-8)

**目标**：162 张牌渲染流畅，完整一局无崩溃

| ID | 任务 | 验收标准 |
|---|---|---|
| T-601 | 牌桌 UI：三副牌手牌区渲染（含排序/分组） | 真机帧率 ≥ 50fps |
| T-602 | 手牌选择 + 出牌动画 + 桌面区布局 | 4 人视角清晰 |
| T-603 | 状态差量更新（对接事件流 + snapshot） | 1 局 60+ 动作无错漏 |
| T-604 | 亮王/抠庄/进贡/还贡/扣底 UI 交互（领域层已就绪，纯 UI 工作） | 规则手册示例局可点出来 |
| T-605 | 倒计时/快捷语/音效（基础版） | 体验过关 |
| T-606 | 结算页（分数/血数/升级展示） | 与服务端结算一致 |

**Demo**：真人 + 3 bot 真机打完完整一局。

## Sprint 7: 打磨 + Bot 拟人化 (2026-11，Week 9-11)

**目标**：朋友拿手机就能玩，不觉得粗糙

| ID | 任务 | 验收标准 |
|---|---|---|
| T-701 | Bot 拟人化：随机思考时长 0.8-2.5s + 出牌策略多样化 | 真人测试难分辨 |
| T-702 | 断线重连体验（重进房间恢复手牌与桌面） | 杀进程重进 ≤ 5s 恢复 |
| T-703 | 性能优化（包体/内存/首屏） | 包体 ≤ 20MB 分包后首包 ≤ 4MB |
| T-704 | 异常兜底（卡死检测/驱动的 stuck 广播处理） | 无静默卡局 |
| T-705 | 真人局测试 ≥ 10 局（朋友内测） | 无 P0 问题 |

**Demo**：朋友扫码进体验版，无指导完成一局。
