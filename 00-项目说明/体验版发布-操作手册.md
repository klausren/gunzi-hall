# 体验版发布 - 操作手册

> 适用：个人主体微信小游戏账号，**体验版**（不上架、不过审、零资质）
> 朋友玩法：你把朋友微信号加入"体验成员"→ 朋友扫体验版二维码 → 直接玩
> 配套排期见《WBS-v1.md》Sprint 8（T-801~804）

---

## 一、整体链路（先看全景）

```
Cocos Creator 构建 → 微信开发者工具导入 → 上传代码
        → 公众平台后台设为体验版 → 生成二维码
        → 添加朋友微信号为体验成员 → 朋友扫码即玩
                ↑
    你的服务器（公网）承载全部牌局 ←—— 客户端连 ws://你的域名或IP:端口/ws
```

体验版**没有审核环节**，上传即生效（仅体验成员可见可玩）。

## 三、服务器部署（T-801）

体验版阶段一台机器就够（承载几十个朋友）。两个方案：

**方案 A：腾讯云轻量服务器（推荐，约 50-100 元/月）**
1. 购买 2C4G 轻量应用服务器（选带 Docker 或纯 Linux 镜像均可）
2. 装 JDK 17 + Redis，上传 server 工程
3. 启动命令（服务器上）：
   ```bash
   export JAVA_HOME=<jdk17路径>
   cd server
   mvn -pl game-domain install -DskipTests
   mvn -pl game-room exec:java -Dexec.mainClass=com.gunzihall.room.ServerMain -Dexec.args="<端口> <roomId>"
   ```
4. 防火墙放行 WS 端口（如 8080）
5. 进程守护：用 systemd 或 `nohup` + 重启脚本（**重启后牌局由 Redis 命令日志自动重放恢复**，已验证）

**方案 B：家用 Mac 常驻**
- 省钱但 IP 会变 + 断电断网即全下线，只适合临时演示

⚠️ 部署前必须完成 T-510（WS 鉴权）——现在协议里任何人可冒充任意 playerId，公网裸奔会被乱搞。

## 四、上传体验版（T-802）

1. Cocos Creator → 项目设置 → 填入 AppID
2. 构建发布 → 微信小游戏 → 构建（注意分包配置，首包 ≤ 4MB）
3. 用**微信开发者工具**打开构建产物目录（build/wechatgame）
4. 工具右上角"上传"→ 填版本号（如 0.1.0）和备注
5. 登录 mp.weixin.qq.com → 版本管理 → 开发版本 → 找到刚上传的版本 → **"选为体验版"**

## 五、添加体验成员（T-803）

1. 公众平台后台 → 版本管理 → 体验版 → "体验成员"管理
2. 逐个输入朋友微信号添加（个人主体体验成员上限约 **50-100 人**，具体以后台显示为准）
3. 点"预览/体验版二维码"发给朋友群，或让朋友自己在小程序历史里找

## 六、运维速查（T-804）

| 症状 | 排查 |
|---|---|
| 朋友扫码白屏 | 服务器没起 / 端口没放行；客户端 WS 地址是否指向公网 |
| 全员断线 | 服务器进程挂了：`ps -ef | grep ServerMain`；重启后房间自动恢复 |
| 单人重连 | 已支持：杀小程序重进 → join 同一 roomId 自动恢复手牌（`reconnect:true` 路径） |
| Redis 报错 | `redis-cli ping`；Redis 挂了新房间会降级内存存储，但重启恢复会失效 |
| 看日志 | 服务器 stdout（启动脚本重定向的日志文件）+ `redis-cli llen game:cmdlog:<roomId>` 看牌局命令数 |

## 七、体验版边界（提前告知朋友）

- ❌ 不能被搜索到、无广告、无内购、无排行榜等平台能力
- ❌ 体验成员上限，加满即止
- ✅ 游戏本体功能完整（房间/牌局/bot 补位/断线重连）
- ✅ 随时可上传新版本，体验版即热更新（朋友端重新进入即最新）
